# 🧩 8 Puzzle Solver with GUI

A simple **8 Puzzle Game + AI Solver** built using Python.

It includes:
- 🎮 GUI (click to move tiles)
- 🧠 A* Algorithm to solve the puzzle
- ▶️ Step-by-step solution animation

---

## 📦 Installation

Clone the repository:

    git clone https://github.com/your-username/8-puzzle.git
    cd 8-puzzle

Install dependencies:

    pip install PyQt5

---

## ▶️ Run the Project

    python Gui.py

---

## 🎯 How to Use

1. Run the program  
2. Click tiles to move them  
3. Press **Solve** button  
4. Watch the AI solve the puzzle step-by-step  

---

## 🧠 How It Works

- The puzzle is a 3×3 grid  
- `_` represents the empty space  
- The AI uses the **A\*** algorithm  
- Heuristic: number of misplaced tiles
